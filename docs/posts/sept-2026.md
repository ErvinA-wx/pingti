## Wiki 更新

- 站内搜索引擎现已支持 **[Section Filters](https://i.ibb.co/99gXbTyD/image.png)** / [2](https://i.imgur.com/J1csfSu.png)（游戏、音频、阅读等），在某些情况下可以提升结果质量。感谢 anarchydr 完成这项工作。

- 已在备份页面添加 FMHY 的 **[.onion](http://fnp47tywqhwygfkkik3dkgreocdbevjslzs6fw4zbotomcbqeuyahjqd.onion/)** 版本。感谢 @saber 制作。

- 已添加 FMHY **[Bookmark Extension](https://github.com/mian196/fmhy-bookmarks-extension)**，支持自动更新。感谢 @Simon Riley 制作。

- FMHY **[Raycast Search Extension](https://www.raycast.com/akshit_mehta/fmhy-search)** 现已上线，感谢其贡献者提出想法并为大家完成这项工作。

- 已添加 [Query Parameter](https://i.imgur.com/S67dReX.png) / [2](https://i.ibb.co/yFyybyfX/Untitled.png) 支持（?q=searchquery）。示例：`https://pingti.org/?q=test`。感谢 @flower 完成这项工作。

- 根据 **[Polls](https://challonge.com/woium3fu/fullscreen)** 及投票期间的讨论，重新调整了 [Anime Streaming Sites](https://pingti.org/video#anime-streaming) 的顺序，感谢所有参与投票的人，也恭喜所有排名上升或保持高位的站点。[Before vs After](https://i.ibb.co/JW4dqsH7/Untitled.png) / [2](https://i.imgur.com/sNqUdG7.png)

- 电子产品购物板块已变得过于臃肿，因此决定将其拆分为几个新的子板块，以便更易于浏览。感谢 @jochen 提出想法。新子板块：[Electronics / Tech](https://pingti.org/misc#electronics-tech)、[Mobile / Phones](https://pingti.org/misc#mobile-phones)、[Cameras](https://pingti.org/misc#cameras)、[PC Hardware / Building](https://pingti.org/misc#pc-hardware-building)、[TV / Monitors](https://pingti.org/misc#tv-monitors)、[Audio Equipment](https://pingti.org/misc#audio-equipment)、[Keyboards / Mice](https://pingti.org/misc#keyboards-mice)、[Gaming Equipment](https://pingti.org/misc#gaming-equipment)

- 已在教育板块添加 [AI / ML Learning](https://pingti.org/educational#ai-ml-learning) 分区。

- 已在教育历史板块添加 [Military / Conflict History](https://pingti.org/educational#military-conflict-history) 分区。感谢 @Yeet 提出想法并收集站点。

- 已在浏览器游戏板块添加 [Racing / Driving](https://pingti.org/gaming#racing-driving) 分区。

- 已在索引板块下添加 [Random Sites / Discovery](https://pingti.org/misc#random-sites-discovery) 分区。

- Minecraft 工具分类已 [thoroughly revised](https://i.ibb.co/svg60Qp2/Untitled.png) / [2](https://i.imgur.com/7V6rWeo.png)。其中包括重新整理并精简部分条目，以便更易于浏览。感谢 @Myuui、@Flower、@Jul Mik、@Yoshi/MTG、@litekin 协助完成。

- 已移除“切换星标”与“切换索引”之间的互斥限制，两个开关现在可以 [same time](https://i.ibb.co/gMHfjG08/image.png) / [2](https://i.imgur.com/sqPgOK3.png) 启用。感谢 Zenith 完成这项工作。

## 已添加星标 ⭐

- 已在游戏下载板块为 [GoG Revived](https://pingti.org/gaming#download-games) 加星，它是 gog-games 的 1:1 存档，并带有更新。

- 已在视频下载站点板块为 [downloadeverythingfromeverywhere](https://pingti.org/video#download-sites) 加星，这是一个聚合器，可抓取多个托管站，其中一些支持一键下载。

- 已在移动端社交媒体应用板块为 [raincord](https://pingti.org/mobile#social-media-apps) 加星，这是适用于 Android 和 iOS 的修改版 Discord 客户端，Kettu 的继任者，支持插件，开发团队优秀，目前使用者反馈运行良好。

- 已在流媒体聚合板块为 [Movy](https://pingti.org/video#stream-aggregators) 加星，流媒体速度快，UI 质量高，是近几个月出现的较好站点之一。

- 已在 Steam 工具板块为 [LuaTools](https://pingti.org/gaming-tools#steam-epic) 加星，这是类似 SteamMidra 的 Steam 多功能工具 + manifest 工具，但更流畅，且不会触发 Defender。

- 已在音乐推荐板块为 [Shfl](https://pingti.org/audio#curated-recommendations) 加星，推荐来自音乐撰稿人和艺术家，拥有庞大的曲库、指南、主题歌单以及 [more](https://i.ibb.co/jP4w9jzF/image.png) / [2](https://i.imgur.com/129i3Dk.png)。 

- 已在图书推荐板块为 [NPR's Books We Love](https://pingti.org/reading#book-recommendations) 加星，[reflects thousands](https://i.imgur.com/px72ucF.png) / [2](https://i.ibb.co/Kxw7L73t/image.png) 来自其数百名记者、评论人和员工的精选推荐。

- 已在 Android 图片图库板块为 [Refra + Right Gallery](https://pingti.org/mobile#image-galleries) 加星，两者都有非常出色的 UI、丰富的功能，并受到试用者的好评。

- 已在 Minecraft 托管工具板块为 [Crafty Controller](https://pingti.org/gaming-tools#hosting-tools) 加星，这是跨平台服务器控制器，可在浏览器中运行，支持文件上传、整合包导入等功能。

- 已在 Linux 游戏板块为 [SLSsteam](https://pingti.org/linux-macos#linux-gaming) 加星，这是带 DLC 解锁器和模拟成就的 Steam 客户端修改版。

- 已在多模型站点板块为 [Together.ai](https://pingti.org/ai#multiple-model-sites) 加星，每日额度不错，免费模型可靠，并支持网络搜索。

- 在 Internet Radio 中加星 [AccuRadio](https://pingti.org/audio#internet-radio)，预编程的主题频道涵盖数百种风格，无限跳过以及 [more](https://i.ibb.co/6JwVfm8Q/image.png) / [2](https://i.imgur.com/ODhkBNk.png)。

- 在 Music Discovery 中加星 [NTS Radio](https://pingti.org/audio#music-discovery)，由超过 [600 resident hosts](https://i.ibb.co/HDYDQWXB/image.png) / [2](https://i.imgur.com/8ckHCwU.png) 的全球社区主导，包括音乐人、DJ、艺术家和唱片收藏家，还有嘉宾节目和特别企划。 

- 在 MOBA Tools 中加星 [Rose](https://pingti.org/gaming-tools#moba-tools)，LoL 皮肤管理器 / 解锁器，使用安全，没有任何人报告过任何问题，拥有游戏中的每一款皮肤（仅在屏幕上显示）。

- 在 iOS Social Media 中加星 [RyukGram](https://pingti.org/mobile#social-media-apps-1)，积极维护的 Instagram 调整工具，试用过的人反馈良好，似乎是目前的最佳选择。

- 在 iOS Audio 中加星 [8SPINE](https://pingti.org/mobile#ios-audio)，基于模块的在线观看 + 下载应用，界面美观，设置丰富，并支持无损播放（配合特定模块）。

- 在 Language Learning 中加星 [Yomitan](https://pingti.org/educational#multi-language)，功能丰富的浏览器弹窗词典，支持自定义主题、anki 集成等。

- 在 Coding Benchmarks 中加星 [DeepSWE](https://pingti.org/ai#coding-benchmarks)，非常可靠，更新频繁，测试模型的所有推理能力。

- 在 Local AI Frontends 中加星 [Cherry Studio](https://pingti.org/ai#local-ai-frontends)，设置简单 + 界面美观。

## 已移除的内容

- 移除了 nitter + xcancel，因为两者都被 X 强制 [shut down](https://i.ibb.co/tjszjwK/image.png) / [2](https://i.imgur.com/j3HYkmB.png)。

- 取消了 Netlify 的加星，因为其不再提供 10GB / 100GB 带宽套餐，转而采用额度更少的积分系统。

- 取消了 squid(wtf) 的加星，因为其现在仅支持 KHInsider 和 JioSaavn。
