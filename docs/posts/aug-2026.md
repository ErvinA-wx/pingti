## Wiki 更新

- 新增 **[URL Search Support](https://i.ibb.co/kVdvPwnc/image.png)** / [2](https://i.imgur.com/v13FI4y.png)，现在可以搜索完整的 URL 或 URL 内的文本。默认关闭，点击搜索栏中的链接图标即可启用。感谢 @Lou、@Manu 和 @Bread 促成此事。

- 为 FMHY 新增了 **[Semantic Style Search](https://search.fmhy.bid/)**，对自然语言的处理效果应该不错。感谢 @Zenith 制作。

- 新增了一个名为 [Monolith](https://i.ibb.co/QjFYWTw9/image.png) / [2](https://i.imgur.com/fwZMOCw.png) 的主题。使用 JetBrains Mono，面向 HiDPI 显示器。感谢 @Zenith 制作。

- 新增了一个 [RSS Style Changelog Tracker](https://d.fmhy.bid/rss.xml)。感谢 @Zenith 制作。

- 将阅读推荐拆分为 3 个子板块：[Books](https://pingti.org/reading#book-recommendations) / [Comics](https://pingti.org/reading#comic-recommendations) / [Manga](https://pingti.org/reading#manga-recommendations)。感谢 @Dan 完成此项工作。

- 在视频工具中新增了 [IPTV Players](https://pingti.org/video#iptv-players) 板块，感谢 @RansomQ 完成此项工作。

- 在社交媒体中新增了 [TikTok Tools](https://pingti.org/social-media-tools#tiktok-tools) 板块。

- 根据 [the polls for it](https://challonge.com/rtdxi8qg/fullscreen) 期间的结果（及相关讨论）重新排列了流媒体聚合站。感谢所有参与投票的人。[Before vs After](https://i.ibb.co/VYsz7PbR/Untitled.png) / [2](https://i.imgur.com/XS9RUNN.png)

- 根据投票结果重新排列了游戏重打包站，感谢所有参与投票的人。[Before vs After](https://i.ibb.co/MyyqwQ6z/image.png) / [2](https://i.imgur.com/shPiyop.png)

- 将当前聚焦的搜索高亮和滚动到匹配项的高亮改为使用 [theme colors](https://i.ibb.co/39z3CZDv/image.png) / [2](https://i.imgur.com/UNHsaiZ.png)。

## 已添加星标 ⭐

- 在文件托管站中为 [0807](https://pingti.org/file-tools#file-hosts) 加星，10GB，文件保留 90 天（自最后一次下载起），开发团队不错，且目前口碑良好。

- 在游戏下载中为 [ZeiGames](https://pingti.org/gaming#download-games)（原 RexaGames）加星，库很大，托管速度快，游戏更新及时。 

- 在 ROM 板块中为 [LoLROMs](https://pingti.org/gaming#rom-sites) 加星，较新的合集，涵盖热门和冷门主机，有数千款游戏，支持一键下载。

- 在游戏模组中为 [Thunderstore](https://pingti.org/gaming-tools#game-mods) 加星，提供模组和模组管理器，主要面向 Unity 游戏（也有其他游戏），库很大，部分人更喜欢它而非 Nexus。 

- 在图书推荐中为 [StoryGraph](https://pingti.org/reading#book-tracking-databases) 加星，图书追踪/推荐网站，功能非常丰富，部分人更喜欢它而非 GoodReads。

- 在漫画推荐中为 [Comic Book Reading Orders](https://pingti.org/reading#comic-recommendations) 加星，拥有海量阅读顺序目录，可追溯至 60 年代。 

- 为 [The Book Prize Index](https://pingti.org/reading#book-recommendations) 加星，不错的图书奖项及获奖图书索引。

- 在优化工具中为 [OptiScaler](https://pingti.org/gaming-tools#optimization-tools) 加星，Windows 游戏超分辨率工具，利用游戏运动矢量获得更好效果，不像 Lossless Scaling 那样出现画面扭曲。

- 在影视下载中为 [MKV BASE](https://pingti.org/video#download-sites) 加星，库非常大，托管站也不错。

- 在动漫在线观看中为 [Yeanime](https://pingti.org/video#anime-streaming) 加星，界面美观，播放速度快，似乎颇受欢迎。

- 在重定向绕过中为 [Bypass (lc)](https://pingti.org/internet-tools#redirect-bypass) 加星，效果不错，支持许多网站。

- 在隐私搜索引擎中为 [Startpage](https://pingti.org/privacy#search-engines) 加星，本质上是隐私性更好的 Google 前端，在某些情况下结果优于其他隐私搜索引擎。

## 已移除的内容

- 移除了 Cromite，因为它现在已落后 3 个主要 Chromium 版本，存在许多 bug，且开发者表示正在休息；如果将来它回归，会重新添加。

- 将 Nightcord 加入不安全列表，他们过去似乎被抓到过 [logging discord tokens](https://i.ibb.co/gbG0SYhM/image.png)。注意，我们并未在 FMHY 上列出此项，只是想帮助传播这一信息。
